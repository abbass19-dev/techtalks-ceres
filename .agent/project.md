# CÉRES - The Interactive Nutrition Analyzer

## Project Overview
CÉRES is a full-stack nutrition analysis web app built with Next.js, designed to help users interactively analyze the nutritional breakdown of their meals and track their daily goals. The backend uses MongoDB for data persistence.

## Key Features

### 1. Nutrition Analysis
- **Instant Breakdown**: Input a list of ingredients and quantities to instantly receive a complete nutritional profile (Calories, Protein, Carbohydrates, Fat, and Fiber).
- **Simple & Fast**: Clean and highly responsive UI designed for quick answers.

### 2. Personal Tracking
- **Dashboard & Statistics**: View daily summaries, recent meals, and engaging nutrition charts.
- **Nutrition Goals**: Set custom daily calorie goals and macro targets.
- **Meal History**: Save previously analyzed meals and access historical data anytime.

### 3. User Management
- **Secure Authentication**: Complete user authentication (with middleware) to keep personal data and history private.
- **Personalized Profile**: Store fundamental metrics like weight, height, and age for tailored insights.

## Tech Stack
- Frontend/Backend: Next.js (App Router)
- Database: MongoDB
